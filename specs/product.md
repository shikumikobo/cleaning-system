# 全体の仕様（cleaning：清掃業のシステム）

変えない決まりは [constitution.md](constitution.md)、データの形（ER図）は [data-model.md](data-model.md)。機能ごとの要件は `NNN-*/requirements.md`。

## 1. だれのためのものか

マンション・ビルの定期清掃を請け負う、社員とパートで数人〜数十人の清掃会社。仕事は、管理会社やオーナーから受ける清掃と、そこから派生する小さな仕事（ゴミの回収、植栽、電球の交換、入居者の困りごとへの対応など）。

困りごと（ねらい）：

- 依頼（だれから・いつまでに・何を）が社長の頭と Excel にあり、抜けや遅れが出る。ほかの人に渡せない
- 見積の作成に手間がかかり、案件と見積と請求がつながっていない
- スタッフに渡す小口現金と領収書の整理が手作業
- 管理会社やオーナーに、写真や書類を渡す手間がかかる
- 現場の写真がスタッフのスマホに散らばり、清掃の報告書を事務所で写真を貼って作り直している
- だれがいつどの建物に行くかが紙やホワイトボードにあり、予定どおり行ったか、報告書が出たかを後から確かめにくい。初めての現場の場所が伝わりにくい

1つの環境に何社でも登録できる（会員制）。同じものを、受託でお客さんの環境に入れることもある。

## 2. 役割

会社ごとに、人の役割を1つ決める。1人が複数の会社に入ることもできる。

| 役割 | だれ | できること（あらまし） |
|---|---|---|
| 管理者 | 社長・事務の責任者 | 会社のすべて。利用者の招待と役割の変更、会社の情報、金額 |
| 社員 | 事務・営業 | 案件・見積・清掃の契約・請求・取引先・建物の登録と編集、作業の割り当てと予実、金額。利用者の管理はできない |
| スタッフ | 現場の人（パートを含む） | 自分の担当の案件と作業の予定、作業の開始・終了の記録、地図と道案内、現場の写真の撮影、担当の作業の清掃報告書の作成、自分の小口現金とレシート。金額と見積は見えない |
| 外部 | 管理会社・オーナーの担当者 | 許可された建物の、進み具合・共有されたファイル・提出した見積と清掃報告書だけ（専用ページ） |
| 運営 | しくみ工房 | 会社の作成と試用の管理。会社の業務のデータは普段は読めない |

## 3. 言葉

| 言葉 | 意味 |
|---|---|
| 会社（テナント） | システムを使う清掃会社。データはここで分ける |
| 拠点 | 会社の営業所・支店 |
| 取引先 | 仕事を頼む側。管理会社かオーナー |
| 建物 | 清掃する物件（マンション・ビル） |
| 部屋 | 建物の中の部屋。入居者の名前は持たない |
| 案件 | 1つの依頼。依頼元・建物（部屋）・分類・内容・期限・担当・状況を持つ |
| 案件の入口 | 依頼が来た道（管理会社から、清掃の報告から、オーナーから など） |
| 見積 | 取引先・建物に出す見積書。案件から作ることも、案件なしで作ることもできる。明細（品名・数量・単価）を持ち、提出・承認の状況がある |
| 清掃の契約 | 取引先と建物について、清掃の中身と金額を決めたもの。種類は「定期」と「単発（特別清掃）」。承認された見積から作る |
| 頻度 | 定期の清掃を行う間隔。週1・週2などの「週に◯回（曜日）」、「月2回」「月1回（第◯◯曜日 または ◯日）」、「◯か月に1回」「年◯回」 |
| 基本の清掃 | 定期の契約で毎回行う作業の項目と、その月額 |
| オプション | 基本に追加する作業（ガラス清掃、床のワックス、高圧洗浄 など）。オプションごとに頻度と金額を決める |
| 特別清掃 | 1回だけ行う清掃（入居前の清掃、ワックスがけ、エアコン清掃 など）。単発の契約にし、行う日と金額を決める |
| 請求書 | 取引先への請求。定期の契約の月額、その月に行ったオプションと特別清掃、終わった案件の金額をまとめる。発行・送付・入金の状況がある |
| 小口現金 | スタッフに渡す現金と、その出入りの記録（出納帳） |
| レシート | 小口現金で払ったときの領収書の画像と、読み取った金額・日付 |
| 専用ページ | 外部の人だけが入る画面 |
| 作業 | 建物で、ある日に行う清掃。建物・日・担当・作業の項目を持つ。清掃の契約の頻度から予定として作る。特別清掃と案件から作ることもある |
| 作業の予定 | 作業ごとの、行う日・始まりと終わりの時刻・担当のスタッフ・作業の項目 |
| 作業の実績 | 作業ごとに実際に行った、始まりと終わりの時刻・行った項目・清掃報告書。スタッフが現場で記録する |
| 予実 | 作業の予定と実績の比べ。行っていない作業、時刻のずれ、行わなかった項目、出ていない報告書を出す |
| 建物カルテ | 建物ごとの現場の情報。入り方、鍵の場所、駐車場、ゴミの日、管理人の連絡先、注意すること。スタッフも見られる |
| 建物の位置 | 建物の住所から求めた緯度と経度。地図に出し、道案内に使う |
| 現場の写真 | 作業や案件の現場で撮った写真。建物（部屋・場所）・撮った日時・撮った人・種類（前・後・気づき）を持つ |
| 清掃報告書 | 1回の作業の報告。作業の項目ごとの実施の有無、写真（前と後）、気づき、所見を持ち、作成・確認・提出の状況がある |
| 報告のひな形 | 建物ごとの作業の項目（エントランス、階段、ゴミ置き場 など）と並び。報告書はここから作る |

| 番号 | 機能 | 中身 | TODO |

| 001 | 会社と利用者 | 会社（テナント）・拠点、ログイン、招待、役割と権限の表、会社で分ける RLS、変更の履歴の土台 | 3-48 |

| 009 | 清掃報告書 | 作業の登録、建物ごとの報告のひな形、スタッフが現場で報告書を作る（項目のチェック・写真の前後・気づき）、社員の確認、外部への提出（専用ページ）、印刷（PDF は画面の印刷） | 3-61 |
| 010 | 清掃の契約（定期・単発） | 承認された見積から契約を作る。定期は頻度（週◯回・月2回・月1回・◯か月に1回 など）と基本の清掃、オプションごとの頻度と金額。単発は特別清掃の日と金額。契約から作業の予定を作る。契約の変更（頻度・金額・オプション）と終了 | 3-62 |
| 011 | 請求 | 月ごとに、定期の月額・その月に行ったオプションと特別清掃・終わった案件を取引先ごとにまとめて請求書にする。請求書は1枚ごとに税を1回かけ、インボイスの書き方にする。発行・送付・入金の状況、印刷、会計ソフトに渡す CSV | 3-63 |
| 012 | 作業の予定と実績 | 予定表（日・週・月、スタッフごと・建物ごと）、担当の割り当てと入れ替え、重なりの警告。スタッフはスマホで自分の予定を見て、開始・終了と行った項目を記録する。予実（行っていない作業、時刻のずれ、行わなかった項目、出ていない報告書）の一覧と、月ごとの集計 | 3-64 |
| 013 | 地図 | 建物の住所から位置を求めて保存する（ずれたら地図で直せる）。建物と、その日の作業の場所を地図に出す。スマホの地図アプリで道案内を開く。作業の開始・終了のときだけ、スタッフの了承を得て位置を記録し、建物から離れていれば知らせる。現場では建物カルテと一緒に見る | 3-65 |
| 014 | データの取り込み | 取引先・建物・部屋・清掃の契約を、Excel・CSV から一度に登録する。ひな形のファイル、取り込む前の確かめの画面、エラーの行の一覧、同じものの重なりの確かめ | 3-66 |
| 015 | お知らせ | スマホへの通知（PWA）とメール。予定の変更、明日の作業、期限の近い案件、出ていない報告書、見積の承認、請求の入金の遅れ。人ごとに受け取る種類を選べる | 3-67 |
| 016 | 売上と粗利 | 契約・建物・取引先ごとの月の売上と、費用（小口の支払いと、手で入れる外注・材料の費用）を引いた粗利。前の月・前の年との比べ。管理者と社員だけが見る | 3-68 |

- 番号は足した順で、作る順番ではない。作る順番は次の通り
  - 004 → 010 → 011：見積から契約、契約と案件から請求
  - 005 → 008：写真は 005 のファイルの置き場所を使う
  - 008・010 → 009：報告書は写真を使い、作業の予定は契約から作る
  - 009 → 012：予実で報告書が出ているかを見る
  - 012 → 013：その日の作業の場所を地図に出す
  - 006 は 001 の後ならいつでも作れる
  - 010 → 014：契約まで取り込めるようにする
  - 012 → 015：知らせる出来事が出そろってから作る
  - 006・011 → 016：売上は請求から、費用は小口から集める
- 試用の間は、001 の「運営が会社を作り、管理者を招待する」形で始める。自分での登録と課金は 007

### 後で決める候補（試用で要望を聞いてから）

- 鍵の管理（貸し出しと返却、だれが持っているか）
- 外注先の管理（協力会社への作業の依頼、外注の費用、支払い）
- 資材・消耗品（在庫、建物ごとの使った量）
- 苦情と品質の点検（苦情を案件の種類の1つとして受け、巡回の点検の結果を残す）
- 取引先への月の報告（その月の報告書と写真を、取引先ごとに1つにまとめて専用ページで渡す）
- ほかの言葉での表示（スタッフの画面を英語などでも出す）

## 5. 範囲の外

- シフトの作成、勤怠と給与の計算（012 は作業ごとの開始・終了を記録するが、出勤・退勤と給与には使わない）
- スタッフの位置を常に追うこと（013 は作業の開始・終了のときだけ記録する）
- 会計ソフトそのもの（006 と 011 は CSV の書き出しまで）
- 請求書の郵送と、入金の自動の照合（入金は人が記録する）
- 入居者の個人の情報
